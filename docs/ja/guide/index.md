# コントロール一覧

各章では、コントロールの既定の外観、主なプロパティ、公開API、実行できるC++とPythonのサンプルを紹介します。[環境構築](/ja/basics/01_install_and_setup)を済ませたら、用途に合う章を選んでください。

|分類|コントロールの章|
|---|---|
|フォームとテキスト|[window](/ja/guide/controls/window-and-text/window)、[label](/ja/guide/controls/window-and-text/label)、[button](/ja/guide/controls/window-and-text/button)、[textbox](/ja/guide/controls/window-and-text/textbox)|
|選択と状態|[checkbox](/ja/guide/controls/selection-and-status/checkbox)、[radiobutton](/ja/guide/controls/selection-and-status/radiobutton)、[progressbar](/ja/guide/controls/selection-and-status/progressbar)、[slider](/ja/guide/controls/selection-and-status/slider)、[numericupdown](/ja/guide/controls/selection-and-status/numericupdown)|
|コレクションとデータ|[combobox](/ja/guide/controls/collection-and-data/combobox)、[listbox](/ja/guide/controls/collection-and-data/listbox)、[treeview](/ja/guide/controls/collection-and-data/treeview)、[listview](/ja/guide/controls/collection-and-data/listview)、[grid](/ja/guide/controls/collection-and-data/grid)|
|レイアウトとコンテナー|[panel](/ja/guide/controls/layout-and-container/panel)、[scrollpanel](/ja/guide/controls/layout-and-container/scrollpanel)、[splitter](/ja/guide/controls/layout-and-container/splitter)、[tabcontrol](/ja/guide/controls/layout-and-container/tabcontrol)（[tabpage](/ja/guide/controls/layout-and-container/tabcontrol#tabpage)を含む）|
|コマンドと表示|[menubar](/ja/guide/controls/command-and-display/menubar)、[toolbar](/ja/guide/controls/command-and-display/toolbar)、[image](/ja/guide/controls/command-and-display/image)、[screen](/ja/guide/controls/command-and-display/screen)、[blank](/ja/guide/controls/command-and-display/blank)|

図はWARPによるオフスクリーン描画です。実行結果の図では、各章のC++サンプルを日本語の表示文言で撮影しています。Python版でも同じコントロールとプロパティを使います。継承したプロパティ、メソッド、イベントは[共通インターフェース](/ja/guide/controls/common-api)を参照してください。
