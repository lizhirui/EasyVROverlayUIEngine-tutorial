# Control Directory

Each control chapter introduces the default appearance, common properties, public interfaces, and independent C++ and Python examples. First complete the [environment configuration](/en/basics/01_install_and_setup), then select chapters as needed.

|Groups|Control Chapters|
|---|---|
|Forms and Text|[window](/en/guide/controls/window-and-text/window)、[label](/en/guide/controls/window-and-text/label)、[button](/en/guide/controls/window-and-text/button)、[textbox](/en/guide/controls/window-and-text/textbox)|
|Selection and Status|[checkbox](/en/guide/controls/selection-and-status/checkbox)、[radiobutton](/en/guide/controls/selection-and-status/radiobutton)、[progressbar](/en/guide/controls/selection-and-status/progressbar)、[slider](/en/guide/controls/selection-and-status/slider)、[numericupdown](/en/guide/controls/selection-and-status/numericupdown)|
|Collections and Data|[combobox](/en/guide/controls/collection-and-data/combobox)、[listbox](/en/guide/controls/collection-and-data/listbox)、[treeview](/en/guide/controls/collection-and-data/treeview)、[listview](/en/guide/controls/collection-and-data/listview)、[grid](/en/guide/controls/collection-and-data/grid)|
|Layouts and Containers|[panel](/en/guide/controls/layout-and-container/panel), [scrollpanel](/en/guide/controls/layout-and-container/scrollpanel), [splitter](/en/guide/controls/layout-and-container/splitter), [tabcontrol](/en/guide/controls/layout-and-container/tabcontrol) (including [tabpage](/en/guide/controls/layout-and-container/tabcontrol#tabpage))|
|Commands and Display|[menubar](/en/guide/controls/command-and-display/menubar)、[toolbar](/en/guide/controls/command-and-display/toolbar)、[image](/en/guide/controls/command-and-display/image)、[screen](/en/guide/controls/command-and-display/screen)、[blank](/en/guide/controls/command-and-display/blank)|

Screenshots of each chapter are rendered off-screen by the SDK using WARP. The renderings use the C++ examples in the chapter, and the Python examples use the same controls and properties. Inherited properties, methods, and events are referred to in [basic interfaces](/en/guide/controls/common-api).
