## SteamVR空間での操作

EasyVROverlayUIEngineの`window`は、3D空間に浮かぶ独立した操作面です。VRコントローラーを使って直接操作できます。

### レーザーでのクリックと両面操作

- **レーザーでクリック（Trigger）**。左右のコントローラーからレーザーが出ます。ボタン、入力欄、メニューなどに向けてトリガーを引くと、クリックできます。
- **表面と裏面の操作**。ウィンドウを回転させて裏面が手前に来たときも、レーザーでクリックやドラッグができます。
- **ウィンドウ面の重なり**。ポインターがキャプチャされていない場合、レーザーは最も手前の可視ウィンドウ面で止まります。無効化されたウィンドウ面やモーダルダイアログで操作がブロックされたウィンドウ面も、背後のウィンドウを遮ります。背後を操作するときは、手前のウィンドウを移動する、照準を変える、モーダル操作を終える、のいずれかを行います。
- **スティックによる滑らかなスクロール**。スクロールバー付きの`listbox`、複数行の`textbox`、`scrollpanel`にレーザーを向け、同じ手の**サムスティック（Thumbstick）**を上下に倒します。深く倒すほどスクロールが速くなります。

### 片手での移動、両手での回転、角のハンドル操作

ウィンドウの周囲には、位置、角度、曲率を調整する操作領域があります。

![曲率調整用の角と両手操作用のリング](/images/ja/vr_curvature_and_handles.png)

|操作する場所|操作方法|結果|
|---|---|---|
|**ウィンドウの空白部分（Grip）**|参照対象が`world`または`body`のときに、片手のグリップボタンを押し続けます。|**6DoFで移動・回転**し、ウィンドウを任意の位置にドラッグできます。|
|**操作リングのブロック（Grip）**|ウィンドウの周囲にある操作リングのブロックを、左右の手で1つずつつかみます。|**両手で回転軸を制約**します。ブロックの組み合わせから回転軸（`X`、`Y`、`Z`など）を自動的に固定し、片手で回転させる場合のぶれを抑えます。|
|**左下の曲率ハンドル／右下のスケールハンドル**|操作する角にレーザーを向け、**トリガー（Trigger）を押しながら**コントローラーのスティックを倒します。|左下では、**スティックを左右に倒して**水平の円筒面の曲がり角を調整します。操作上限は160°で、**左下をダブルクリックすると平面に戻ります**。右下では、**スティックを上下に倒して**ウィンドウの`physical_scale`（物理スケール）を調整します。|

::: tip トラッキングの参照対象を切り替える
タイトルバー右上の閉じるボタンの隣に、**`⊕`トラッキング切り替えボタン**があります。クリックすると`world`、`body`、`head`、`left`、`right`の間で切り替わります。たとえば`left`を選ぶと、ウィンドウは左手のコントローラーに追従します。
:::

## テキスト入力とグローバルショートカット

EasyVROverlayUIEngineには、**VRの仮想キーボードモード**と**物理キーボードモード**があります。

### 入力バー、IME候補ウィンドウ、仮想キーボード

VRで`textbox`または編集可能な`combobox`をクリックすると、Engineが入力欄の真下に次の入力UIを中央揃えで表示します。

![入力バー、IME候補ウィンドウ、仮想キーボードの3段構成](/images/ja/vr_input_stack.png)

1. **入力バー（上段）**には現在の入力言語、有効なIMEの名前、**「入力方式の切替」**ボタンが表示されます。このボタンでモーダルダイアログを開き、言語、IME、仮想キーボードのレイアウトを切り替えます。
2. **IME候補ウィンドウ（中段）**には、ピンインやかなの変換前文字列と候補一覧が表示されます。数字キー、スペースキー、レーザーでのクリックで候補を選び、入力を確定します。英語の直接入力など候補が不要なIMEでは、候補ウィンドウの代わりに入力バーが表示されます。
3. **仮想キーボード（下段）**は独立した104キーのキーボードです。仮想キーボードモードで表示されます。`Pause`で物理キーボードモードに切り替えた後も、入力バーとIME候補ウィンドウは使えます。

### 物理キーボードモードとグローバルショートカット

|ショートカット|適用条件|操作内容|
|---|---|---|
|**`Pause`**|現在のVRウィンドウが有効|**物理キーボードモード**を切り替えます。有効な間、Engineはキー入力を現在のVRウィンドウに届け、Windowsのデスクトップアプリには送信しません。|
|**`Alt+Shift`**|物理キーボードモードで現在のウィンドウがある|入力言語を切り替え、その言語で前回使ったIMEを復元します。`textbox`のフォーカスは維持されます。|
|**`Alt`**|物理キーボードモードで現在のウィンドウに有効な`menubar`がある|押している間はニーモニックの下線を表示します。単独で押して離すと、キーボードによるメニュー操作に入るか、そこから抜けます。|
|**`Ctrl + Shift`**|物理キーボードモードで現在のウィンドウがある|現在の入力言語の中でIMEを切り替えます。|
|**`Tab` / `Shift + Tab`**|現在のウィンドウがある|ウィンドウ内のコントロールに設定されたTab順で、次または前のコントロールにフォーカスを移します。|
|**`PrintScreen`**|物理キーボードモードで現在のウィンドウがある|現在のVR視点を撮影し、Windowsのクリップボードへコピーします。|
|**`Ctrl + Pause`**|**グローバル**（ウィンドウを選択していなくても有効）|**Desktop（VRアプリランチャー）**の表示と非表示を切り替えます。|
|**`Ctrl + Alt + Pause`**|**グローバル**|**`body`のトラッキング中心**と**`world`の空間オフセット**をリセットし、ウィンドウの基準を現在のヘッドセットの正面に戻します。|

::: warning `Pause`で切り替わらない場合
物理キーボードモードを有効にする前に、対象のVRウィンドウをレーザーでクリックします。これでEngineに有効な現在のウィンドウが設定されます。物理キーボードモードを終了すると、キー入力はWindowsデスクトップに戻ります。
:::

## インストール時に付属するアプリ

付属アプリと入力コンポーネントは`app/`にあります。Engineは`bin/config.json`に従ってDesktop、layout、IMEを起動します。以下はすべて[インストール先](/ja/basics/01_install_and_setup)からの相対パスです。

### 1. Desktop（VRアプリランチャー）

![Desktopのアプリランチャー](/images/ja/desktop.png)

図は、ユーザー設定にアプリを追加していない状態のDesktopです。5つのアイコンはシステム設定に登録されたC++デモ、Pythonデモ、ファイルマネージャー、フォームデザイナー、タスクマネージャーです。

- **表示**。`Ctrl+Pause`を押します。Engineは設定に指定された`app/desktop/easyvrui_desktop.exe`を使用します。
- **配置とアプリ一覧**。表示のたびに`world`を参照し、現在のヘッドセットの正面に配置します。Desktopは、`app/desktop/config.json`の付属アプリと`%USERPROFILE%\easyvrui\desktop\config.json`のユーザー追加アプリを、アプリIDを基準にメモリ内で統合します。追加・削除はユーザー設定だけに書き込みます。
- **非表示**。右上の閉じるボタンはDesktopのウィンドウを非表示にします。バックグラウンドプロセスは動作を続け、もう一度`Ctrl + Pause`を押すとすぐに表示できます。

### 2. File Manager（VRファイルマネージャー）

![File Managerのフォルダー表示](/images/ja/file_manager.png)

- **起動**。Desktopから開くか、`app/file_manager/easyvrui_file_manager.exe`を直接実行します。
- **主な機能**。VR内でローカルディスクやフォルダーを閲覧し、パスを確認してアプリを起動できます。複数のウィンドウを同時に開けます。

### 3. Task Manager（VRタスクマネージャー）

![Task Managerのアプリセッション一覧](/images/ja/task_manager.png)

- **起動**。Desktopから開くか、`app/task_manager/easyvrui_task_manager.exe`を直接実行します。
- **主な機能**。Engineに接続中のすべてのアプリセッション、ウィンドウの`name`と`title`、メモリ使用量、CPU・GPUの使用率をリアルタイムで確認できます。指定したウィンドウを閉じたり、アプリプロセスを終了したりできます。Desktopと入力コンポーネントはシステムで保護されます。

### 4. 独立した仮想キーボード（`standard_104`）

![標準104キーの仮想キーボード](/images/ja/layout_keyboard.png)

- 実行ファイルは`app/layout/standard_104/easyvrui_layout_standard_104.exe`です。
- 独立したプロセスとして標準プロトコルでEngineに接続します。独自のキーボードレイアウトを実装し、標準のレイアウトと差し替えることもできます。

### 5. 中国語・英語・日本語のIME

![ピンインと日本語のIME候補ウィンドウ](/images/ja/ime_candidates.png)

図の上がピンイン、下が日本語の候補ウィンドウです。ピンインの候補ウィンドウは中国語、日本語の候補ウィンドウは日本語を固定で使います。各候補ウィンドウの上にある入力バーはSDKの表示言語を使うため、図ではどちらにも日本語の「入力方式の切替」が表示されています。

- **EasyVRUI拼音**は`app/ime/cn/easyvrui_pinyin/easyvrui_ime_chinese_pinyin.exe`です。Rimeの実行用辞書はアプリディレクトリの`rime/chinese_pinyin/`、ユーザー辞書と動的な単語頻度は`%USERPROFILE%\easyvrui\chinese_pinyin`にあります。`Shift`を単独で押すと中国語と英語を切り替えます。ソースに付属する`import_user_dictionary.py`で、Sogouの`.scel`や`.tsv`をインポートできます。
- **EasyVRUI English**は`app/ime/en/easyvrui_english/easyvrui_ime_english.exe`です。英語の直接入力を提供します。
- **EasyVRUI日本語**は`app/ime/jp/easyvrui_japanese/easyvrui_ime_japanese.exe`です。Rimeの実行用辞書はアプリディレクトリの`rime/japanese/`、ユーザーデータは`%USERPROFILE%\easyvrui\japanese`にあります。スペースキーで変換、Enterキーで確定できます。`F6`から`F10`までの変換と、`Alt+Backquote`または`Ctrl/Alt/Shift+CapsLock`でのモード切り替えにも対応します。

続けて[最初のwindow](/ja/basics/03_first_window)を実行し、初期表示とクリック後の図を比べて、入力とイベントのディスパッチを確認しましょう。
